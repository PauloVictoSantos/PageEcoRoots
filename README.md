## 📋 Sobre o Projeto

O **EcoRoots** é um projeto desenvolvido com o objetivo de conectar pessoas a práticas mais sustentáveis. Através de uma interface amigável e recursos inteligentes (IA), a plataforma busca educar, engajar e fornecer ferramentas para que os usuários possam reduzir sua pegada ecológica e adotar hábitos que preservem o meio ambiente.

Acesse o projeto homologado aqui: [EcoRoots na Vercel](https://ecoroots-ai.vercel.app/)

## ✨ Funcionalidades Principais

- **Interface Intuitiva & Responsiva:** Design moderno adaptável para dispositivos móveis, tablets e desktops.
- **Integração com IA (EcoRoots AI):** Recursos inteligentes para auxiliar usuários em dúvidas sobre reciclagem, sustentabilidade e práticas eco-friendly.
- **Conteúdo Educativo:** Seções dedicadas à conscientização sobre o ecossistema e a importância de fincar "raízes" sustentáveis para o futuro.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

- **HTML5** & **CSS3** - Estruturação e estilização da aplicação.
- **JavaScript (ES6+)** - Lógica de programação e dinamismo do ecossistema.
